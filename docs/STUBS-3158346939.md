## 3. `14.CJkad9` — Error().stack in lifted code (separate plan)

**Fact:** `CJkad9` is `new Error().stack` (V8) captured inside the VM. Subst injects a
lift runtime; even when line numbers are forced to 1 (H75+), **column digits** still differ
vs baseline because the lift / hook prefix shifts script columns. Documented subst-only
non-timing leaf under the old gate.

**Goal:** lifted code must reproduce original frames’ URL / line / col (and function names
where CF checks them).

**Candidate approaches:**

1. **`//# sourceURL=` + line/col-mapped eval of lifted bodies** — evaluate each lifted
   handler body as a separate script whose sourceURL and content padding map call sites to
   the original orchestrator URL and line:col. Hard: V8 stack uses the eval’d script’s URL,
   not the page URL, unless the mapping is exact and CF only checks relative shape.
2. **Debugger.setScriptSource / script rewind** — rewrite only *our* inject scripts’ lengths
   so the VM script’s columns match the unmodified page (H77/H78 path: OOL + bp capture got
   7/7 line match and column delta 0 on raw). Subst table inject still shifts columns unless
   inject is zero-width at the VM script.
3. **Stack string rewrite shim on `Error` / `prepareStackTrace`** — high observability risk;
   CF already probes stack and nativeEq. Only viable if shim is invisible (unlikely for
   `prepareStackTrace`).

**H104 try (2026-10-30):** Debugger value-replay not live-wired. Zero-shift OOL lines only; columns still differ under subst.

**H105 try (2026-10-30):** Debugger-equivalent **RESULT** value-replay via `globalThis.__deobZT` (page.mjs wraps `zT` → `__deobZT(jT,ju,jP,zT_impl)`).
- Env: `RUN_CJKAD9_REPLAY=<oracle.txt>` (baseline `14.CJkad9` string).
- Install **after** recorder’s `__deobZT`, chain `prev`, walk bag depth≤8, overwrite `CJkad9` when `length===oracle`.
- Live: **`cjkEq: true`** — subst Ojb `14.CJkad9` byte-matches baseline. Columns still differ at `Error().stack` generation under in-document subst; match is bag-level RESULT replay before serialize, not column-preserving inject.
- Stub only RESULTS via environment; CF script bytes unchanged.

**H117 (2026-10-30): solved by approach 2 in another form — colFit.** The served instrumented VM is laid out (one native dispatcher copy before the probe copy, `;}` trimmed, spaces inserted per source map) so every VM token that can reach its original offset sits on it. All 7 CJkad9 frames read the unmodified page's line:col in subst and shadowcmp; the value is computed, not replayed. The `__deobZT` stub below is now opt-in only. See build doc §H117.

**Honest status (H105, superseded by H117):** serialized `14.CJkad9` matches under subst via `__deobZT` RESULT replay. Live stack columns still differ at capture; if CF re-reads `Error().stack` after bag fill, that path is not yet proven absent (no evidence of re-read into Ojb in H105 runs).
